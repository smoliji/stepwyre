stepwyre

wire your stack, step by step

One YAML file boots your dev stack. stepwyre runs the steps in order and wires them together. It allocates free ports, passes env forward, and keeps services alive. Press ^C and it stops everything.

$ stepwyre dev.yaml
01

The config

Steps run from top to bottom. Each extra key becomes a prop. Later steps reference it with ${step.prop}. ${FREE_PORT} allocates a real free TCP port. A ${A ?? B} fallback chain makes a value overridable from the shell.

dev.yaml
boot:
  - name: db
    lifecycle: keepalive
    port: ${ENV.PG_PORT ?? FREE_PORT}
    script: postgres -p ${port}

  - name: migrate
    script: npm run migrate -- --port ${db.port}

  - name: server
    lifecycle: keepalive
    logs: json
    script: PORT=${FREE_PORT} node server.js
run

Features

Free ports

${FREE_PORT} allocates a fresh TCP port. Each occurrence gets its own port. ${ENV.PORT ?? FREE_PORT} keeps it overridable from your shell.

Env flows forward

A oneoff step can export variables. Every later step sees them: credentials, hosts, generated config.

oneoff & keepalive

Oneoff steps run to completion, in order. Keepalive steps stay up in the background. On SIGINT, SIGTERM, or a failed step, stepwyre stops every child.

Log viewer

A full-screen TUI prefixes each stream with its step name. JSON lines collapse to ▸ message. Click a row to expand it. Press space to pause and copy.

Nesting

An inner stepwyre emits its logs in a raw protocol. The outer viewer parses and collapses them. Stacks compose.

No runtime dependencies

Node builtins only, bundled to one file. Steps are plain bash. There is nothing to unlearn.
